# Optional SWBFSpy client information

SWBFSpy is a community-operated replacement for the defunct GameSpy master service. It is third-party, is not included in this egg, and is not affiliated with or endorsed by LucasArts or its successors. Any optional client-side setup happens only on a player's own computer.

Approved information pages:

- https://info.swbfgamers.com/downloads.html
- https://info.swbfgamers.com/faq.html

Use a legitimate Steam, GOG, or original CD/DVD client and review the community page and package instructions. Before making a client-side change, back up the original `BattlefrontII.exe` and any other file named by those instructions. Keep the backup so the original installation can be restored.

This repository does not mirror third-party payloads, provide patched executables, describe manual binary editing, or alter the dedicated-server executable. A client-side change does not by itself make this unmodified server appear in a public browser; server-side master-service compatibility is separate and is not implemented here. A direct-connect join was verified on 2026-11-01 with one legitimate SWBFSpy-patched Steam client. Public-browser discovery, reconnect behavior, and other client builds remain unverified and depend on the client build and network path.
